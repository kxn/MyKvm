> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按单处理 iced 桌面端 8 个遗留 issue（#99–#106），每单独立分支与 PR，门禁全绿后合并并统一真机验证。

**Architecture:** 单 checkout 顺序分支流（一个 issue 一个 `codex/issueN-*` 分支），避免共享工作区并行冲突；每单 TDD（先红后绿）；实现由 subagent 完成、控制器评审；PR 关联 issue 并以 `Closes #编号` 收口。

## 执行流程（每单）

1. 从 main 切新分支 `codex/issueN-<slug>`，记录基线 BASE commit。
2. 控制器写 task brief（.superpowers/sdd/），派发 fresh implementer subagent；subagent TDD：先写失败测试 → 跑红 → 实现 → 跑绿 → 自审 → 提交。
3. 控制器评审 diff（必要时派 reviewer subagent），发现问题派 fix subagent 复修并复评。
4. 门禁全绿（fmt/test/clippy/rustdoc）。
5. `tea pulls create` 建 PR（描述含关联 issue、改动摘要、测试证据、人工验证例外），合并 PR（`Closes #编号`），删除本地+远端分支。
6. 在 `.superpowers/sdd/progress.md` 追加完成记录；同步 HANDOFF.md。
7. 全部完成后统一真机验证（黑窗、居中、断开、菜单动作、鼠标模式、状态栏、对话框、中英文与字体）。
