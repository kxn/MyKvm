# Project Scaffold Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立 my_ipkvm 的 Rust 工作区脚手架，包含核心模块边界、基础测试、文档入口、本地 git 仓库和 Gitea 远端。

**Architecture:** 工作区按设计文档拆成 `ipkvm-core`、`ipkvm-video`、`ipkvm-session`、`ipkvm-rfb`、`ipkvm-desktop`、`ipkvm-headless`。当前只放可编译的最小类型、接口和测试，不实现真实采集、真实 RFB 服务或真实串口控制。

**Tech Stack:** Rust 1.89、Cargo workspace、edition 2024、标准库单元测试、MIT 许可证、Gitea `tea` CLI。

## Global Constraints

- 正文文档使用中文；协议名、产品名、接口名、文件名、URL 可保留原文。
- 不使用 Qt、PyQt、PySide。
- 不引入 GPL 依赖。
- 当前最小版本不引入 FFmpeg/GStreamer。
- 当前最小版本只支持 CH9329，不实现 CH9350L。
- 当前不考虑安全、鉴权、TLS、公网访问。
- 无头版方向是 VNC/RFB-first，网页复用 noVNC。

fn ch9329_frame_uses_header_length_and_sum_checksum() {

    assert_eq!(frame.as_bytes(), &[0x57, 0xAB, 0x00, 0x02, 0x03, 0x00, 0x00, 0x04, 0x0B]);
}

#[test]
fn pointer_mapping_clamps_to_ch9329_absolute_range() {
    let rect = ViewRect { x: 10, y: 20, width: 100, height: 50 };
    assert_eq!(map_pointer_to_ch9329(Point { x: 10, y: 20 }, rect), Ch9329Point { x: 0, y: 0 });
    assert_eq!(map_pointer_to_ch9329(Point { x: 110, y: 70 }, rect), Ch9329Point { x: 4095, y: 4095 });
}
