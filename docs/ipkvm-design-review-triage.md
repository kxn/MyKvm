# k3 设计审查意见采纳清单

日期：2026-07-31

审查来源：`docs/ipkvm-design-review.md`

目标文档：`docs/ipkvm-coarse-design.md`

## 采纳并进入当前最小版本

| 建议 | 处理 |
| --- | --- |
| RFB `DesktopSize` 动态分辨率 | 采纳。会话层不再假定视频尺寸固定，视频层提供尺寸变化事件，RFB 当前最小版本支持 `DesktopSize` 伪编码。 |
| 相对鼠标回退 | 采纳。鼠标模式改为绝对/相对可切换，桌面端阶段 1 支持相对模式，网页端需要 Pointer Lock 或定制 noVNC 页面层。 |
| 失焦自动释放按键 | 采纳。视频视图失焦、窗口关闭、串口断开、控制者切换时触发 `release_all()`。 |
| OS 自动重复按键去重 | 采纳。键盘状态机忽略重复 `key_down`。 |
| 6KRO 溢出策略 | 采纳并明确策略。第 7 个普通键按下时拒绝新键，保留当前已按下键，并记录丢弃计数。 |
| CH9329 设备探测 | 采纳。串口模块打开候选端口后使用读信息命令探测合法回包。 |
| CH9329 在线探测 | 采纳。读信息命令也作为低频心跳。 |
| CH9329 波特率切换 | 采纳。优先 115200，失败回退默认波特率，具体配置命令以协议文档和硬件验证为准。 |
| 主控端快捷键限制说明 | 采纳。文档写明 `Alt+Tab`、`Win`、`Ctrl+Alt+Del` 等无法由普通窗口稳定捕获。 |
| DPI 缩放测试 | 采纳。坐标换算单元测试覆盖 1.25、1.5 等非整数缩放。 |
| 采集格式默认偏好 MJPEG | 采纳。1080p 自动格式选择优先 MJPEG。 |
| 采集卡 EDID 预期 | 采纳。写入硬件现实约束和验证清单。 |
| 默认绑定 `127.0.0.1` | 采纳。它不是安全子系统，只是避免默认无鉴权暴露。 |
| 未知伪编码处理 | 采纳。识别但不实现的伪编码应忽略而不是断连，测试覆盖。 |
| 串口写入串行化 | 采纳。所有输入事件进入单一串口写入队列。 |
| 剪贴板粘贴转模拟键入 | 采纳。进入阶段 2，但定位为“文本转模拟键入”，不是双向剪贴板同步。 |
| 快照接口 | 采纳。阶段 2 增加 `/api/screenshot`。 |
| 状态接口 | 采纳。阶段 2 增加 `/api/status`。 |
| noVNC 静态资源内嵌 | 采纳。阶段 2 内嵌 noVNC，并锁定版本和许可证说明。 |
| 屏幕键盘 | 采纳。阶段 1/2 提供特殊组合键、F 键等基础屏幕键盘。 |

## 部分采纳

| 建议 | 处理 |
| --- | --- |
| Caps Lock / NumLock 状态处理 | 部分采纳。CH9329 无法回读目标机 LED 状态，因此不能真正保证目标机锁定键状态未知时的大小写正确。当前设计只承诺 `en_US` 可映射字符，默认假定 Caps Lock 关闭，并在文档中说明限制。 |
| noVNC WebSocket `binary` 子协议 | 部分采纳。RFB over WebSocket 必须发送二进制帧；若客户端请求 `Sec-WebSocket-Protocol: binary`，服务端可回应以兼容旧代理。但现代 noVNC 不应被设计成强制依赖该非标准子协议，实际以锁定版本测试为准。 |
| libjpeg-turbo | 部分采纳。它适合作为 MJPEG 解码优先候选，许可证属于可接受范围；但 Rust 绑定、动态/静态链接和发布方式要在引入依赖前单独审计。 |
| 相对鼠标网页端 Pointer Lock | 部分采纳。方向正确，但 noVNC 原生能力不能预设；如果 noVNC 页面层拿不到相对位移，需要定制页面层。 |

## 后置

| 建议 | 处理 |
| --- | --- |
| Wake-on-LAN | 后置到阶段 5。它有用且成本低，但不是 KVM 画面和输入闭环的必要条件。 |
| 输入事件 JSONL 日志 | 后置到阶段 5。它属于审计/安全扩展，当前用户明确要求安全相关先不考虑。 |
| 帧录制 | 后置到阶段 5。存储、隐私和容量策略都不是当前最小版本问题。 |
| GPU YUY2/NV12 转 RGB | 后置到阶段 4。方向正确，但第一目标仍是先跑通采集、显示和输入闭环。 |

## 未采纳

当前没有完全否定的建议；主要是阶段前后和实现方式做了收敛。
