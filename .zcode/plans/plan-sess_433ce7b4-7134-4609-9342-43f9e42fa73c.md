# 组装正式 ipkvm-headless 二进制

## 目标

把 `crates/ipkvm-headless/src/main.rs` 从脚手架替换成可运行后台进程：**同时提供 RFB TCP（5900）+ noVNC 网页/RFB WebSocket（6080）**，用 Y4M 动态视频 + FakeCommandQueue。用户做完后可 `cargo run` 起服务，浏览器连 http://127.0.0.1:6080 看 noVNC 画面，或 VNC 客户端连 5900。

## 实施步骤

1. **Cargo.toml**：给 `[[bin]] ipkvm-headless` 加 `required-features = ["demo"]`（demo feature 已含 core+video mock）。
2. **重写 src/main.rs**：参照 transport_exclusion 测试的共享模式，组装 TCP+HTTP 双传输 + 输入泵，命令行参数 `--assets/--bind/--tcp/--http/--fps`，Ctrl+C 超时兜底关闭。
3. **集成测试 tests/headless_process.rs**：验证 TCP banner + WS banner + 静态资源 + gate 互斥(409) + 干净关闭。
4. **全量验证**：fmt/test/clippy/doc。
5. **手工验证**：起服务、浏览器连 6080、VNC 连 5900。
6. **文档同步**：README + coarse-design。
7. **开 issue、提交、开 PR、合并**。
